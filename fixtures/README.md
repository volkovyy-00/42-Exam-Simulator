# fixtures

Original exercises (MIT, written for this repo) in the same layout as `content/`
(DESIGN.md §5.2). Point any service at them with `CONTENT_DIR=./fixtures` to develop and test
without the private 42-derived pool. Expected outputs were generated by compiling the
references with `cc -Wall -Wextra -Werror -std=gnu17`; WP2's regen script must reproduce them.
